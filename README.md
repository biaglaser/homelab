# Homelab

My personal homelab project, built around a Raspberry Pi 5 (for now...)

## Goals

- Explore Linux, networking, and infrastructure management
- Build personal cloud and storage services
- Develop and deploy custom applications
- Practice security and DevSecOps
- Experiment with automation and IoT

## Hardware

- Raspberry Pi 5
- External (Kingston NV3) SSD

## Repository Structure

- `infrastructure/` - System configuration and infrastructure automation
- `services/` - Self-hosted services and deployment configurations
- `apps/` - Custom applications
- `scripts/` - Utility and maintenance scripts
- `docs/` - Documentation and architecture decisions
- `.github/` - GitHub Actions workflows

Initial setup in progress.
